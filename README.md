# 📖 Overview

**SmartGym Management System** is a desktop application designed to digitalize and simplify the management of fitness centers.

The application enables gym administrators to manage members, monitor attendance, process subscriptions, track payments, generate reports, and maintain operational data through a modern and user-friendly interface.

Developed with **JavaFX**, the project follows a modular architecture to ensure scalability, maintainability, and efficient management of gym activities.
